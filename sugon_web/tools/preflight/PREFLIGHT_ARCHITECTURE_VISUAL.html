资源画像

resource_requirements.yaml：维护各模块资源峰值、配额最大值和 worker 放大规则。

规则引擎

health_rules.yaml：定义系统盘阈值、Pod 异常数、巡检状态、失败项和告警项。

输出产物

preflight-results + allure-result：健康 JSON、矩阵日志、截图、Allure 报告。

设计原则：一个关键词触发完整检查，前端页面、后台状态、运维巡检和资源画像分层治理；检查失败先阻断自动化，失败项直接辅助定位环境问题。

关键词入口

Jenkins MARK 填写 preflight-all，即可一次性展开前端、后台和运维巡检检查。

执行约束

前置检查默认串行执行，避免多个巡检任务同时操作同一套运维页面。

代码分层

pytest 负责真实采集，profiles 维护规则，health_check 负责统计和输出矩阵。

失败定位

通过健康 JSON、Jenkins 日志、Allure 步骤、截图和后台状态判断问题来源。
