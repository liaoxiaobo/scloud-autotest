## 测试步骤

### 场景1：解绑公网IP验证（用例421102）

#### 步骤1：进入USM列表页

- 操作：进入资源中心-安全-云堡垒机高级版USM页面
- 预期：进入堡垒机页面成功，列表可正常显示

#### 步骤2：进入实例详情页查看跳转地址

- 操作：点击实例名称进入实例详情页，查看跳转地址字段
- 预期：跳转地址显示URL的跳转链接（可点击跳转）

#### 步骤3：解绑公网IP

- 操作：返回列表页，选择该实例，执行操作"解绑公网IP"，在弹窗中选择已绑定的公网IP，点击确定
- 预期：
  - 打开解绑公网IP弹窗
  - 关闭弹窗后提示"执行成功"
  - 该实例网络列只展示固定IP，不再展示公网IP

#### 步骤4：验证解绑后详情页跳转地址

- 操作：点击实例名称进入实例详情页，查看跳转地址字段
- 预期：跳转地址显示"非直连网络需要绑定公网ip才可使用！"

## ⚠️ 实现注意事项

- 本用例无SSH后台操作需求，全部为UI前端验证

### 2. Fixture强制约束

- 实现测试步骤或前置条件的自动化脚本前，**必须**阅读 `sugon_web/case_specs/fixtures_index.md`

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的fixture：

- `usm_instance` fixture（session级）：创建USM实例并自动绑定EIP，session结束时自动清理。通过 `usm_instance["name"]` 获取实例名
- `usm_page` fixture（function级）：初始化云堡垒机高级版USM页对象，导航到USM服务

### 4. 实例复用说明

- **本用例使用 `usm_instance` fixture 提供的已绑定EIP的USM实例**
- 测试脚本中通过 `usm_instance["name"]` 获取实例名称作为测试目标
- 实例的清理由 `usm_instance` fixture 的 teardown 机制自动完成

### 5. 解绑操作说明

- 解绑公网IP操作需要新增 `usm_unbind_eip` 方法到 `UsmPage` 页面对象
- 解绑流程：点击操作 → 选中弹窗中已绑定的公网IP → 确认 → 验证网络列不再显示公网IP
- 解绑后需验证跳转地址字段显示"非直连网络需要绑定公网ip才可使用！"
