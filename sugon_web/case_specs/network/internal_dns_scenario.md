# 测试用例：内网解析详情页-解析记录-主机记录与SRV记录解析生效验证

## 所属模块
- 一级模块：网络
- 二级模块：内网解析
- 三级模块：解析记录

## 适配范围

### 存储适配
- 该用例不支持的存储：无
- 说明：代码侧无需额外 `skip_stor`

### 架构/节点限制
- 架构限制：无
- 节点要求：无
- 说明：代码侧无需额外 `skip_arch(...)`、`skip_if_nodes_less_than(...)`

## 前置条件
- 依赖内网解析基础创建能力，可参考禅道依赖用例 `3401`
- 预置 1 个可用 VPC，并在该 VPC 子网下准备两台弹性云服务器 `ecs1`、`ecs2`
- `ecs1` 作为解析验证客户端，需可通过 SSH/VNC 登录
- `ecs2` 作为解析记录目标主机，需已知其内网 IP
- 测试环境内网 DNS 服务地址为 `169.254.169.253`

## 测试步骤

1. 操作
   - 操作：创建一条关联目标 VPC 的内网解析，并进入该内网解析详情页
   - 预期：内网解析创建成功；详情页可以正常打开；域名、关联 VPC 等基础信息显示正确

2. 操作
   - 操作：切换到“解析记录”页签，新建 A 类型主机记录，主机记录填写 `www`，TTL 填写 `300`，值填写 `ecs2` 的内网 IP
   - 预期：解析记录创建成功；列表中新增 `www.<内网解析域名>`，其类型、TTL、值与填写内容一致

3. 操作
   - 操作：登录 `ecs1`，执行 `ping www.<内网解析域名>`
   - 预期：可以 ping 通，解析结果指向 `ecs2` 的内网 IP

4. 操作
   - 操作：继续在当前内网解析下新建根域 A 记录，主机记录留空，TTL 填写 `300`，值填写 `ecs2` 的内网 IP
   - 预期：解析记录创建成功；列表中新增 `<内网解析域名>` 根域记录，类型、TTL、值显示正确

5. 操作
   - 操作：登录 `ecs1`，执行 `ping <内网解析域名>`
   - 预期：可以 ping 通，解析结果指向 `ecs2` 的内网 IP

6. 操作
   - 操作：继续新建 A 类型子域名解析记录，主机记录填写 `cdn`，TTL 填写 `300`，值填写 `ecs2` 的内网 IP
   - 预期：解析记录创建成功；列表中新增 `cdn.<内网解析域名>`，类型、TTL、值与填写内容一致

7. 操作
   - 操作：登录 `ecs1`，执行 `ping cdn.<内网解析域名>`
   - 预期：可以 ping 通，解析结果指向 `ecs2` 的内网 IP

8. 操作
   - 操作：继续新建 SRV 类型解析记录，主机记录填写 `testsrv`，TTL 填写 `300`，值填写 `1 99 3306 <ecs2内网IP>`
   - 预期：解析记录创建成功；列表中新增 `testsrv.<内网解析域名>`，类型为 `SRV`，值展示与填写内容一致

9. 操作
   - 操作：登录 `ecs1`，执行 `dig @169.254.169.253 testsrv.<内网解析域名> srv`
   - 预期：可以正常解析出 SRV 记录，返回结果中包含 `1 99 3306 <ecs2内网IP>`
