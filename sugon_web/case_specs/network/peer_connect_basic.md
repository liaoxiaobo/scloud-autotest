# 测试用例：对等连接-创建和删除

## 所属模块
- 一级模块：网络
- 二级模块：对等连接

## 适配范围

### 存储适配
- 该用例不支持的存储：无

### 架构/节点限制
- 架构限制：无
- 节点要求：无

## 测试步骤

1. 操作
   - 操作：预置 2 个可用 VPC，分别作为本端 VPC 和对端 VPC
   - 预期：2 个 VPC 创建成功并处于可用状态

2. 操作
   - 操作：进入对等连接页面，点击新建，填写名称、本端 VPC、对端 VPC、描述后提交
   - 预期：对等连接创建成功，页面出现成功提示

3. 操作
   - 操作：在列表页查看新建的对等连接
   - 预期：列表中存在该对等连接，名称、本端 VPC、对端 VPC、描述正确，状态正常

4. 操作
   - 操作：删除创建的对等连接
   - 预期：删除操作成功，列表中不再显示已删除的对等连接
