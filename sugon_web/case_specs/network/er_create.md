# 测试用例：企业路由器-新建功能验证

## 基本信息
- 用例编号：5921、420810
- 所属产品：曙光云Stack
- 一级模块：网络
- 二级模块：企业路由器

## 适配范围

### 存储适配
- 该用例不支持的存储：无

### 架构/节点限制
- 架构限制：无
- 节点要求：无

## 前置条件

1. 已登录云平台，具备企业路由器创建权限
2. 环境中存在可用的 "Autotest" 集群

## 测试步骤

### 场景1：HA实例新建功能验证（用例5921）

1. 进入企业路由器模块
   - 操作：依次点击：资源中心 -> 网络 -> 企业路由器
   - 预期：可以正常进入企业路由器列表页

2. 创建HA企业路由器
   - 操作：点击新建按钮，按如下要求填写表单信息
     - 名称：输入自定义字符串，如 `er-ha-autotest`
     - 集群：选择 Autotest
     - HA选项：保持默认开启状态
     - 其它字段保持默认值，点击立即创建
   - 预期：
     - 可以正常弹窗/进入创建页面
     - 可以正常输入名称
     - 可以选择主机集群
     - HA选项默认显示为开启状态
     - 创建成功，提示信息正确
     - 列表页显示新创建的记录，名称为输入值，状态为创建中

3. 等待状态变化
   - 操作：等待约2分钟，等待期间每隔20秒点击一下右上角的刷新按钮
   - 预期：新增的记录状态从"创建中"变成"运行中"

4. 验证详情页
   - 操作：在列表页中，点击新创建的企业路由器名称，进入详情页面，查看基本信息tab
   - 预期：
     - 详情页可以正常打开
     - 基本信息tab页可以正常显示企业路由器的名称
     - 状态字段为"运行中"
     - 高可用(HA)字段显示为"开启"

5. SSH后台验证
   - 操作：使用 `ssh_host` fixture 直接SSH连接测试环境的控制节点，执行命令：
     ```bash
     source /root/admin-openrc.sh && scli guest list|grep <实际输入的企业路由器名称>
     ```
   - 预期：
     - 命令执行输出为2行记录
     - 状态均为 RUNNING（HA实例对应2台ECS后端）

## ⚠️ 实现注意事项

### 1. SSH操作强制约束
- 若测试步骤或前置条件中需要SSH到服务器后台或虚拟机后台执行命令，**必须**调用 `sugon_web/common/ssh.py` 中封装好的公共方法
- 禁止在测试代码中直接使用 `paramiko`、`subprocess` 等方式建立SSH连接
- 推荐使用fixture：
  - `ssh_host` fixture：直接SSH连接目标主机（不经过跳板机），用于连接测试环境控制节点执行后台命令

### 2. Fixture强制约束
- 实现测试步骤或前置条件的自动化脚本前，**必须**阅读 `sugon_web/case_specs/fixtures_index.md`
- 查阅fixture强制约束和速查表，确认框架中是否已有可复用的fixture
- **禁止**针对已有的fixture进行重复封装

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的fixture：

- `ssh_host` fixture：直接SSH连接目标主机（不经过跳板机），用于在控制节点执行 `scli guest list` 命令
- `page` fixture：Function级页面实例，每个用例独立页面
- `config` fixture：配置对象，可获取环境配置信息

### 4. 后台命令执行规范
- 所有需要后台长期运行的命令，**必须**使用 `nohup` 命令并在末尾添加 `&` 符号
- 示例：`nohup <command> > /dev/null 2>&1 &`

### 5. 状态轮询说明
- 企业路由器创建后状态变化：创建中 → 运行中
- 列表页有自动刷新机制（每3秒轮询），但测试中也应主动点击刷新按钮辅助验证
- 最长等待时间建议设置为120秒

### 6. HA开关说明
- HA选项是否显示取决于系统策略配置（policy_document），前端根据该配置决定是否渲染HA开关
- HA开启时，后端创建2台ECS；HA关闭时，后端创建1台ECS
- 如环境中不显示HA开关（policy_document=false），则只能创建非HA实例

### 7. 页面元素说明
- 企业路由器服务导航路径：资源中心 → 网络 → 企业路由器
- 新建按钮在列表页左上角，文案为"新建"
- 创建页面为独立路由页面（非弹窗），路径包含 `/create-er`
- 表单字段：名称（输入框）、集群（下拉选择）、HA（开关）、描述（文本域）
- 提交按钮文案为"立即创建"
- 列表页表格列：名称、项目名称、状态、创建时间、HA（条件显示）
- 详情页通过点击列表页名称链接进入，有"基本信息"tab
