## 前置条件

1. 已使用admin账号登录云平台
2. 已预置虚拟私有云（dc1_vpc1），网段13.34.34.0/24，并在该VPC下创建一台弹性云服务器vm1
   - 本VPC及其子网在测试中创建，用于承载vm1
3. 已预置一个非HA类型的物理连接（physical_connection），审批通过，vlan号为205
   - 注意创建物理连接时需要关闭HA
   - 本资源在测试中创建
4. 已预置一个虚拟网关（virtual_gateway），关联模式为虚拟私有云，关联预置的dc1_vpc1
   - 本资源在测试中创建
5. 已预置一个虚拟接口（virtual_interface）
   - 物理连接选择physical_connection
   - 虚拟网关选择virtual_gateway
   - 虚拟子网选择下拉列表中的子网
   - 本端网关：11.22.0.2/24
   - 远端网关：11.22.0.3/24
   - 路由模式：静态路由
   - 远端子网：123.12.0.0/24
   - 本资源在测试中创建

## 测试步骤

### 场景1：vpc类型+非HA+静态路由生效性验证（用例420684）

> 测试数据不可复用，本场景独立创建和清理所有资源。

#### 步骤1：进入VPC详情页的路由表tab

- 操作：进入虚拟私有云模块，在VPC列表页点击预置vpc的名称，进入详情页，再点击路由表tab
- 预期：可以正常进入VPC模块详情页，路由表列表可以正常显示

#### 步骤2：创建自定义路由规则

- 操作：在路由表页面点击新建按钮，在弹出的新建路由表规则页面添加自定义路由：
  - 目的地址：固定值 123.12.0.0/24
  - 下一跳类型：选择"云专线"
  - 下一跳：选择前置条件中预置的物理连接名称
  - 子步骤：
    1. 填写完成后，点击"确定"按钮
- 预期：
  - 弹窗可以正常显示新增自定义路由窗口
  - 自定义路由可以正常创建
  - 创建后在列表中可以查看到该自定义路由
  - 目的地址字段显示为 123.12.0.0/24
  - 下一跳类型字段显示为"云专线"
  - 类型字段显示为"自定义"

#### 步骤3：SSH连接vm1验证静态路由生效

- 操作：使用 `ssh_vm` fixture 连接vm1后台，执行ping命令验证静态路由生效
- 子步骤：
  1. 通过 `ssh_vm.connect(vm_mfip)` 建立SSH连接（vm_mfip为vm1的管理浮动IP）
  2. 执行命令：`ping -c 4 123.12.0.10`，其中123.12.0.10为固定ip地址不需要调整
  3. 验证ping结果：4次全通
  4. 执行命令：`ip ad`，显示当前弹性云服务器的IP地址
  5. 测试脚本记录ping和ip ad两条命令的执行结果，用于结果查询
- 预期：
  - 虚机可以正常SSH连接
  - ping 123.12.0.10 可以正常访问通（4次全通）

## 实现注意事项

### 1. SSH操作强制约束
- 若测试步骤或前置条件中需要SSH到虚拟机后台执行命令，**必须**调用 `sugon_web/common/ssh.py` 中封装好的公共方法
- 禁止在测试代码中直接使用 `paramiko`、`subprocess` 等方式建立SSH连接
- 使用 `ssh_vm` fixture：通过跳板机连接虚机的SSH会话，调用 `connect()` 建立连接，`run()` 执行命令

### 2. Fixture强制约束
- 实现测试步骤或前置条件的自动化脚本前，**必须**阅读 `sugon_web/case_specs/fixtures_index.md`
- 查阅fixture强制约束和速查表，确认框架中是否已有可复用的fixture
- **禁止**针对已有的fixture进行重复封装

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的fixture：

- `vpc` fixture：创建VPC（支持count参数批量创建，返回name、subnet_name、cidr）
- `vm` fixture：创建虚机（支持count参数批量创建，自动绑定MFIP；若引用vpc则自动复用其网络）
- `dc_page` fixture：云专线DC页面对象（已存在于 `testcase/network/conftest.py`）
- `vpc_page` fixture：VPC页面对象（已存在于 `testcase/network/conftest.py`）
- `ecs_page` fixture：弹性云服务器页对象
- `ssh_vm` fixture：通过跳板机连接虚机的SSH会话
- `page` fixture：Playwright页面对象，每个测试函数独立

### 4. 测试数据不可复用说明

由于CSV中"测试数据是否可复用"标记为"否"，本场景独立创建和清理所有资源，不与其他场景共享。考虑到资源之间有强依赖关系且清理顺序严格，建议测试方法中手动管理资源生命周期（创建→测试→清理），避免fixture自动teardown与手动清理顺序冲突。

### 5. 路由规则创建

本用例需要在VPC详情页的路由表tab中创建自定义路由规则。可以使用 `VpcMixin` 中的 `route_rule_create` 方法扩展支持：
- `route_rule_create(vpc_name, dest_cidr, next_hop, next_hop_type, desc)`：
  - `vpc_name`：VPC名称
  - `dest_cidr`：目的地址，如 "123.12.0.0/24"
  - `next_hop_type`：下一跳类型，本用例为 "云专线"
  - `next_hop`：下一跳值，为物理连接名称
  - `desc`：描述，可选

### 6. 路由规则删除

需要在VPC详情页路由表tab中删除自定义路由规则。若 `VpcMixin` 中没有对应的删除方法，需要扩展：
- `route_rule_delete(dest_cidrs)`：支持单个和批量删除路由规则
  - 传入目的CIDR地址定位要删除的规则
  - 点击操作栏"删除"按钮，确认弹窗中点击"确定"

### 7. 物理连接HA开关

本用例创建物理连接时必须关闭HA（ha_enable=False）。创建时弹窗中HA开关默认可能为开启状态，需要在表单中显式关闭HA开关。

### 8. VLAN号冲突处理

审批时使用VLAN号205。若该VLAN已被占用，物理连接创建或审批会失败。建议在测试前清理已使用VLAN 205的残留物理连接。

### 9. 物理连接状态等待

审批通过后需要等待物理连接状态变为"办结"，使用 `dc_page.wait_for_physical_connection_status()` 方法轮询等待。

### 10. 虚拟接口创建前等待

虚拟网关创建后，建议等待约30秒确保资源就绪，再创建虚拟接口。

### 11. ping命令验证

使用 `ssh_vm.run("ping -c 4 123.12.0.10")` 执行ping命令，验证返回结果中是否包含"4 packets transmitted, 4 received"或类似的成功标识（如0% packet loss）。

### 12. 虚拟网关创建弹窗定位

虚拟网关创建使用 `el-dialog` 弹窗（`:append-to-body="true"`），弹窗定位上下文使用 `.el-dialog__wrapper:visible`。

### 13. 虚拟接口创建页面定位

虚拟接口创建为独立页面（通过路由 `/virtual-interface-add`），表单位于 `.add-box > .box` 容器内，使用 `el-form` 表单。

### 14. 网关IP输入处理

本端网关和远端网关各由5个输入框组成（IP四段+掩码位），需要使用 `.ip_input` class 定位并依次填入。

示例：输入 `11.22.0.2/24`
- 第1个 `.ip_input`：11
- 第2个 `.ip_input`：22
- 第3个 `.ip_input`：0
- 第4个 `.ip_input`：2
- 第5个 `.ip_input`：24

### 15. 下拉选项 teleport 处理

Element UI 的 `el-select-dropdown` 选项可能被 teleport 到 body，选择选项时使用 `.el-select-dropdown:visible` 作为上下文定位。

### 16. 断言策略

- 页面操作断言：使用页面元素断言验证路由规则创建成功（列表中包含新规则，字段值正确）
- SSH后端验证：使用 `ssh_vm.run()` 执行ping命令，解析返回结果验证连通性

## 清理数据

### 清理顺序强制要求

本用例的测试数据清理流程必须按照如下顺序执行：

1. **删除自定义路由**：在VPC详情页路由表tab下，删除添加的自定义路由规则
2. **删除虚拟接口**：在虚拟接口列表页，点击操作栏"删除"按钮，确认删除
3. **删除虚拟网关**：在虚拟网关列表页，点击操作栏"删除"按钮，确认删除
4. **注销物理连接**：在物理连接列表页，点击操作栏"注销"按钮，确认注销
5. **删除弹性云服务器vm1**：在ECS列表页删除vm1
6. **删除虚拟私有云dc1_vpc1**：在VPC列表页删除VPC

### 清理注意事项

- 清理顺序不可颠倒：必须先删除路由规则（解除依赖），再删虚拟接口，再删虚拟网关（虚拟接口依赖虚拟网关），再注销物理连接
- 每个清理步骤完成后应验证清理成功（列表中不再显示该实例）
- 测试数据不可复用，每个测试方法包含完整的创建→验证→清理流程
