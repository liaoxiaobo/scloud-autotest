# 测试用例：流量镜像-镜像会话新建功能验证

## 基本信息
- 用例编号：407249、1407249、421687
- 所属产品：曙光云Stack
- 一级模块：网络
- 二级模块：流量镜像

## 适配范围

### 存储适配
- 该用例不支持的存储：无

### 架构/节点限制
- 架构限制：无
- 节点要求：无

## 前置条件

1. 已预置虚拟私有云 **tm-vpc1**（网段无要求），并在其下创建弹性云服务器 **tm-vm1**（创建时名称加前缀 `tm-`）
2. 已预置虚拟私有云 **tm-vpc2**（网段无要求），并在其下创建弹性云服务器 **tm-vm2**（创建时名称加前缀 `tm-`）
3. 已预置流量镜像实例 **tm-inside-test1**，类型为**云内实例**，目的实例选择 **tm-vm1**
4. 已预置流量镜像实例 **tm-outside-test1**，类型为**云外设备**，VLAN 输入 `259`，MAC 地址输入 `fa:16:e3:44:53:47`

> **资源复用说明**：tm-vpc1、tm-vm1、tm-vpc2、tm-vm2、tm-inside-test1 在场景1和场景2中复用；tm-vpc2、tm-vm2 在场景3中复用。各场景测试数据不共享，各场景独立执行并独立清理。

## 测试步骤

### 场景1：镜像会话-新建-云内实例-开启（用例407249）

#### 步骤1：进入流量镜像模块

- 操作：登录云平台后，依次点击 资源中心 -> 网络 -> 流量镜像
- 预期：可以正常进入流量镜像模块，列表页正常显示

#### 步骤2：进入镜像会话Tab页

- 操作：在列表页点击流量镜像实例 **tm-inside-test1** 的名称，进入详情页，选择**镜像会话**Tab
- 预期：详情页正常显示，镜像会话Tab可以正常打开

#### 步骤3：新建镜像会话

- 操作：点击**新建镜像会话**按钮，按以下信息输入：
  - 名称：`tm_session`（常规名称）
  - 是否开启：默认值为开启，保持默认值不变
  - 专有网络：选择 **tm-vpc2** 及其子网
  - 镜像源：选择 **tm-vm2**
  - 方向：选择**全部流量**
  - 描述：`我的流量镜像_-123Abc`
  - 点击**确定**
- 预期：弹窗可以正常打开并输入，提交后创建镜像会话成功

#### 步骤4：验证列表页

- 操作：确认镜像会话列表页显示刚新增的镜像会话
- 预期：镜像会话正常显示在列表页，名称为 `tm_session`、方向为**全部流量**、状态为**在线**、是否开启字段为**是**

## ⚠️ 实现注意事项

### 1. SSH操作强制约束
- 若测试步骤或前置条件中需要SSH到服务器后台或虚拟机后台执行命令，**必须**调用 `sugon_web/common/ssh.py` 中封装好的公共方法
- 禁止在测试代码中直接使用 `paramiko`、`subprocess` 等方式建立SSH连接
- 推荐使用 fixture：
  - `ssh_vm` fixture：通过跳板机连接虚机的SSH会话
  - `ssh_host` fixture：直接SSH连接目标主机（不经过跳板机）

### 2. Fixture强制约束
- 实现测试步骤或前置条件的自动化脚本前，**必须**阅读 `sugon_web/case_specs/fixtures_index.md`
- 查阅fixture强制约束和速查表，确认框架中是否已有可复用的fixture
- **禁止**针对已有的fixture进行重复封装

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的fixture：

- `vpc` fixture：创建VPC（支持 `count` 参数批量创建）
- `vm` fixture：创建虚机（支持 `count` 参数批量创建，自动绑定MFIP）
- `tm_page` fixture：流量镜像页对象（需在 `sugon_web/testcase/network/conftest.py` 中补充，导航到流量镜像服务）
- `ecs_page` fixture：弹性云服务器页对象（用于清理阶段删除ECS）

### 4. 后台命令执行规范
- 所有需要后台长期运行的命令，**必须**使用 `nohup` 命令并在末尾添加 `&` 符号
- 示例：`nohup <command> > /dev/null 2>&1 &`

### 5. 镜像会话Tab页导航说明
- 流量镜像详情页包含多个Tab，镜像会话Tab需要通过点击Tab标签切换
- 新建镜像会话按钮在镜像会话Tab页内
- 镜像会话列表验证在Tab页内完成

### 6. 前置资源创建策略
- 场景1和场景2共享同一套前置资源（tm-vpc1、tm-vm1、tm-vpc2、tm-vm2、tm-inside-test1）
- 场景3独立使用前置资源（tm-vpc2、tm-vm2、tm-outside-test1）
- 由于CSV中标记"测试数据是否可复用"为"否"，各场景应独立创建和清理资源
- 若各场景独立运行，则各自创建所需资源；若合并运行，需注意资源命名冲突

## 清理数据

### ⚠️ 清理顺序强制要求

各场景的测试数据清理流程**必须**按照如下顺序执行：

1. 在镜像会话Tab页，点击列表操作栏的**删除**按钮删除镜像会话（需要删除所有镜像会话）
2. 返回流量镜像列表页，点击列表操作栏的**删除**按钮删除流量镜像实例
3. 进入弹性云服务器模块，删除前置条件中准备的虚机（注意需要从**回收站**中彻底删除）
4. 进入虚拟私有云模块，删除前置条件中准备的虚拟私有云

### 清理注意事项

- 清理顺序不可颠倒，必须严格按照上述顺序依次执行
- 如果在清理过程中某一步骤失败，需先解决该步骤的问题后再继续后续清理
- 每个清理步骤完成后应验证清理成功，再执行下一个清理步骤
- 虚机和VPC的清理由fixture的teardown机制自动完成，但需确保在此之前已完成镜像会话和流量镜像实例的清理
