# 测试用例：内网解析-创建和删除

## 所属模块
- 一级模块：网络
- 二级模块：内网解析

## 适配范围

### 存储适配
- 该用例不支持的存储：无

### 架构/节点限制
- 架构限制：无
- 节点要求：无

## 测试步骤

1. 操作
   - 操作：预置 1 个可用 VPC，作为内网解析关联 VPC
   - 预期：VPC 创建成功并处于可用状态

2. 操作
   - 操作：进入内网解析页面，点击新建，填写域名、关联 VPC、邮箱、描述后提交
   - 预期：内网解析创建成功，页面出现成功提示

3. 操作
   - 操作：在列表页查看新建的内网解析
   - 预期：列表中存在该内网解析，域名、已关联 VPC、描述正确，状态为正常，记录集个数显示正确

4. 操作
   - 操作：删除创建的内网解析
   - 预期：删除操作成功，列表中不再显示已删除的内网解析
