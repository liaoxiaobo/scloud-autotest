- 用例编号：5922, 15922
- 所属产品：曙光云Stack
- 一级模块：网络
- 二级模块：企业路由器

## 适配范围

### 存储适配

- 该用例不支持的存储：无

### 架构/节点限制

- 架构限制：无
- 节点要求：无

## 前置条件

1. 已预置非HA类型企业路由器 `er-noha-autotest`（场景1使用）
2. 已预置HA类型企业路由器 `er-ha-autotest`（场景2使用）
3. 已预置虚拟私有云 `er1_vpc1`，网段为 `173.3.3.0/24`（场景2使用）
4. 场景2中已将 `er1_vpc1` 添加为 `er-ha-autotest` 的连接

## 测试步骤

### 场景1：修改非HA企业路由器基本信息-无连接（用例5922）

#### 步骤1：进入企业路由器列表页

- 操作：登录云平台后，依次点击：资源中心 -> 网络 -> 企业路由器
- 预期：可以正常打开企业路由器列表页

#### 步骤2：打开修改弹窗

- 操作：在ER列表页，点击预置的非HA实例 `er-noha-autotest` 操作栏的"修改基本信息"按钮
- 预期：可以正常点击并打开修改弹窗，弹窗中名称字段的初始值显示为 `er-noha-autotest`

#### 步骤3：修改基本信息

- 操作：在修改弹窗中按如下内容输入：
  - 名称：在原有名称基础上增加 `-modify`，即 `er-noha-autotest-modify`
  - 描述：输入值 `这是autotest修改的描述信息`
  - 点击确定按钮
- 预期：
  - 名称字段可以正常输入
  - 描述字段可以正常输入
  - 点击确定后可以正常提交，显示提交成功的弹窗提示 `修改企业路由器成功`

#### 步骤4：列表页验证修改结果

- 操作：返回列表页，查看修改后的ER信息
- 预期：列表页显示修改后的ER信息，名称为 `er-noha-autotest-modify`

#### 步骤5：详情页验证修改结果

- 操作：点击修改后的ER名称 `er-noha-autotest-modify`，进入详情页
- 预期：详情页显示修改后的ER信息，名称为 `er-noha-autotest-modify`，描述为 `这是autotest修改的描述信息`

## 清理数据

### 清理顺序强制要求

测试数据清理流程**必须**按照如下顺序执行：

**场景1（无连接）：**
1. 删除企业路由器实例 `er-noha-autotest-modify`

**场景2（有连接）：**
1. 删除ER实例下的所有连接
2. 删除企业路由器实例 `er-ha-autotest-modify`

### 清理注意事项

- 清理顺序不可颠倒，必须严格按照上述顺序依次执行
- 如果在清理过程中某一步骤失败，需先解决该步骤的问题后再继续后续清理
- 每个清理步骤完成后应验证清理成功，再执行下一个清理步骤
- 测试数据标记为"不可复用"，测试完成后需要彻底清理所有资源
