## 前置条件

1. 已预置VPC（如vpc1），并在VPC下创建四台虚机：ecs0、ecs1、ecs2、ecs3
2. 在vpc1下，预置负载均衡(基础版)-v2实例lb1-v2
3. 监听器参数配置：
   - 监听器名称：tcp_8080
   - 描述：1234567890edwqWDWQ中文~
   - 协议：TCP
   - 协议端口：8080
   - 资源池名称：backend_1
   - 葭载调度算法：轮询
   - 其他字段保持默认值（如不开启会话保持、不开启健康检查等）

## 测试步骤

### 步骤1：进入负载均衡模块

- 操作：进入负载均衡模块，依次点击：产品与服务 -> 网络 -> 负载均衡SLB
- 预期：可以正常进入负载均衡模块，lbv1列表可以正常显示

### 步骤2：进入监听器详情页

- 操作：在lbv1列表页，点击预置的lb实例名称，进入详情，选择监听器tab
- 预期：详情页可以正常显示

### 步骤3：创建TCP监听器

- 操作：点击新建按钮，按前置条件3中的参数，创建TCP监听器
- 预期：
  - 创建监听器成功并提示信息
  - 监听器详情页显示信息与新建数据一致

### 步骤4：添加资源池成员

- 操作：在lb详情页 -> 监听器tab下 -> 点击监听器名称 -> 选择资源池tab，进入资源池详情后，点击创建按钮，选择ecs1、ecs2、ecs3为该资源池的成员，对应端口为8080
- 预期：
  - 新建成员成功
  - 资源池列表显示信息与新建资源数据一致

### 步骤5：后端虚机配置（ecs1、ecs2、ecs3）

- 操作：进入弹性云服务器模块，ssh_vm.connect("mfip")方式分别登录ecs1、ecs2、ecs3，执行如下操作
- 子步骤：
  1. 创建测试目录：
     ```bash
      cd /root && mkdir test
     ```
  2. 创建测试文件（以ecs1为例，其他虚机注意修改标识）：
     ```bash
     cd /root/test/ && echo "this is ecs1" >> index.html
     ```
  3. 启动web server（使用nohup后台执行，避免占用SSH会话）：
     ```bash
      cd /root/test/ && nohup python3 -m http.server 8080 > /dev/null 2>&1 &
     ```
  4. 轮询等待，直至上一步骤执行的命令输出符合预期的正确结果，最长等到60秒
- 预期：
  - 目录创建成功
  - 文件创建成功
  - 强制轮询等待后，再使用ss -lntp | grep 8080命令检查web服务启动成功，启动成功后再执行以下测试步骤

### 步骤6：内网VIP访问测试

- 操作：在负载均衡列表页，获取本lb实例的网络IP，再通过ssh_vm.connect("mfip")公共方式ssh连接ecs0，然后在ecs0中执行以下命令请求此lb实例：
  ```bash
  curl http://<本lb实例的网络IP>:8080/index.html
  ```
- 预期：
  - 执行成功，显示"this is ecsX"
  - 多次执行后，整体符合1:1:1的轮询规律

### 步骤7：绑定公网IP

- 操作：在负载均衡列表页，针对此lb实例，点击其操作栏的绑定公网ip按钮，绑定公网ip
- 预期：fip绑定成功，可以在列表显示绑定的公网ip地址

### 步骤8：公网IP访问测试

- 操作：在负载均衡列表页，获取本lb实例的公网IP，再通过框架中已封装好的ssh_host()的**fixtures来**ssh连接到本测试环境的物理机，然后在物理机后台通过本lb实例的公网IP来访问负载均衡，再执行以下命令：
  ```bash
  curl http://<本lb实例的公网IP>:8080/index.html
  ```
- 预期：
  - 执行成功，显示"this is ecsX"
  - 多次执行后，整体符合1:1:1的轮询规律
