# 测试用例：IAM-用户管理-创建普通用户

## 基本信息

- 用例编号：3434
- 所属产品：曙光云Stack
- 一级模块：身份认证IAM
- 二级模块：组织管理-用户管理

## 适配范围

### 存储适配

- 该用例不支持的存储：无

### 架构/节点限制

- 架构限制：无
- 节点要求：无

## 前置条件

1. admin 用户已登录云平台（通过 `page` fixture 自动完成登录）
2. 待创建用户参数（账号和用户名使用 `random_data()` 生成唯一值，避免并发冲突）：
   - 账号：`autotest-iam-` + random_data()
   - 用户名：与账号相同
   - 组织管理员：否
   - 角色绑定：默认角色（选择第一个可用角色）
   - 邮箱：`autotest-iam-` + random_data() + `@sugon.com`
   - 手机号：随机生成11位数字
3. 新创建用户的登录密码：**默认与 admin 用户密码相同**（`keystone_sugon`），平台为新用户设置默认密码

## 测试步骤

### 场景1（用例3434）：用户管理-创建普通用户

#### 步骤1：进入运营-统一身份认证IAM页面

- 操作：admin登录后，进入运营侧边栏，点击"统一身份认证IAM"服务
- 预期：页面正常加载，左上角显示"统一身份认证IAM"标题

#### 步骤2：进入组织管理-用户管理页面并打开创建用户弹窗

- 操作：
  1. 选择左侧组织管理菜单
  2. 在组织结构树中展开并选择一个子组织节点
  3. 点击右侧用户管理 tab 页
  4. 点击用户管理 tab 页中的"创建用户"按钮
- 预期：
  - 组织管理页面正常展示
  - 组织结构树可正常展开和选择
  - 用户管理 tab 页正常切换
  - 弹出创建用户弹窗

#### 步骤3：填写用户信息并提交

- 操作：
  1. 在创建用户弹窗中填写用户信息：
     - 账号：`autotest-iam-` + random_data()
     - 用户名：与账号相同
     - 组织管理员：否
     - 角色绑定：默认角色（选择第一个可用角色）
     - 邮箱：账号@ + `sugon.com`
     - 手机号：随机生成11位数字
  2. 点击"确定"按钮提交
- 预期：
  - 用户信息填写正确
  - 创建用户成功，弹窗关闭或提示创建成功
  - 用户管理列表中显示新创建的用户（可通过用户名搜索验证）

#### 步骤4：使用新用户登录验证

- 操作：
  1. 退出当前 admin 登录（通过页面右上角用户菜单退出）
  2. 使用新创建的用户账号登录（账号为步骤3中生成的随机账号，密码为 `keystone_sugon`）
- 预期：
  - 退出登录成功，跳转到登录页面
  - 新用户登录成功，进入云平台首页（URL 无登录页标识）

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的 fixture：

### 4. 后台命令执行规范

- IAM 模块位于运营侧边栏，服务入口路径需通过 SERVICE_PATH_MAP 配置或菜单导航

- 创建用户为弹窗形式，包含账号、用户名、组织管理员开关、角色选择、邮箱、手机号等字段
- 用户创建后需在列表中验证存在

### 6. 断言策略

- **步骤1**：页面元素断言 — 验证页面标题包含"统一身份认证IAM"

- **步骤3**：页面元素断言 — 验证创建成功提示或用户出现在列表

### 7. 测试数据策略

- 用户账号和用户名使用 `random_data()` 生成唯一值（格式：`autotest-iam-` + random_data()）
- 邮箱使用账号名拼接 `@sugon.com` 后缀
- 手机号使用 `random_data()` 生成随机数字串
- 本用例测试数据不可复用，每次执行独立创建和清理
