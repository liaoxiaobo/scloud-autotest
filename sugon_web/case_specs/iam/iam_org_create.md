- 所属产品：曙光云Stack
- 一级模块：身份认证IAM
- 二级模块：组织管理-组织结构树

## 适配范围

- 该用例不支持的存储：无

### 架构/节点限制

- 架构限制：无
- 节点要求：无

## 前置条件

1. admin 用户已登录云平台（通过 `page` fixture 自动完成登录）
2. 待创建组织参数（组织名称使用 `random_data()` 生成唯一值，避免并发冲突）：
   - 组织名称：`autotest-org-` + random_data()
   - 用户名：`sgtest` 或 `autotest-org-user-` + random_data()
   - 邮箱：`autotest-org-` + random_data() + `@sugon.com`
   - 手机号：随机生成11位数字（以138开头）
   - 密码：`Autotest@123`（或符合平台密码策略的强密码：需包含大小写字母、数字、特殊字符，10-32位）
3. 组织创建后，该用户作为组织的初始管理员，可用于后续登录验证

## 测试步骤

### 场景1（用例3278）：组织结构树-创建组织

#### 步骤1：进入运营-统一身份认证IAM页面

- 操作：admin登录后，进入运营侧边栏，点击"统一身份认证IAM"服务
- 预期：页面正常加载，左上角显示"统一身份认证IAM"标题

#### 步骤2：进入组织管理页面

- 操作：在IAM页面中，确认已处于组织管理（组织结构树）视图
- 预期：组织管理页面正常展示，左侧显示组织结构树

#### 步骤3：创建组织

- 操作：
  1. 点击组织结构树区域的"创建组织"按钮
  2. 在创建组织弹窗中填写信息：
     - 组织名称：`autotest-org-` + random_data()
     - 用户名：`autotest-org-user-` + random_data()
     - 邮箱：用户名 + `@sugon.com`
     - 手机号：随机11位数字（138开头）
     - 密码：`12345678Aa`
  3. 点击"确定"按钮提交
- 预期：
  - 创建组织成功，弹窗关闭或提示创建成功
  - 组织结构树中显示新创建的组织

#### 步骤4：使用新组织用户登录验证

- 操作：
  1. 退出当前 admin 登录（通过页面右上角用户菜单退出）
  2. 使用步骤3中创建的用户账号和密码登录云平台
- 预期：
  - 退出登录成功，跳转到登录页面
  - 新用户登录成功，进入云平台首页

#### 步骤5：访问弹性云服务器页面

- 操作：登录成功后，点击"资源中心-计算-弹性云服务器"页面
- 预期：页面正常加载，因新组织用户未绑定项目，页面显示"未绑定项目"或"无权访问"提示

### 3. 可复用Fixture参考

根据 `fixtures_index.md`，本用例可能涉及的 fixture：

### 7. 测试数据策略

- 组织名称、用户名使用 `random_data()` 生成唯一值（格式：`autotest-org-` + random_data()）
- 邮箱使用用户名拼接 `@sugon.com` 后缀
- 手机号使用 `138` + 8位随机数字
- 测试数据可复用：标记为"是"，但组织创建和用户登录为单次流程，无需跨场景复用

## 清理数据

### ⚠️ 清理顺序强制要求

1. 删除创建的组织（在组织管理列表/树中操作）
2. 若组织删除自动清理关联用户，则无需单独删除用户；否则需单独删除用户

### 清理注意事项

- 清理前需先以 admin 身份登录
- 删除组织可能需要确认弹窗
- 若组织下存在用户或其他资源，可能需要先清理子资源
