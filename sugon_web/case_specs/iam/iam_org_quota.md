# 测试用例：一级组织修改配额

## 基本信息

- 用例编号：3278
- 所属产品：曙光云Stack
- 一级模块：身份认证IAM
- 二级模块：组织管理-组织结构树

## 适配范围

### 存储适配
- 该用例不支持的存储：无

### 架构/节点限制
- 架构限制：无
- 节点要求：无

## 前置条件

1. admin 用户已登录平台
2. IAM 页面可正常访问
3. 已存在一级组织（若不存在，测试前需先创建一个一级组织作为被测对象）

## 测试步骤

### 场景1：一级组织修改配额（用例3278）

#### 步骤1：进入 IAM 页面
- 操作：admin 登录后，点击"运营"→"租户"，进入统一身份认证 IAM 页面
- 预期：页面可正常访问，左上角显示"统一身份认证IAM"页面

#### 步骤2：进入组织管理页面
- 操作：点击组织管理，进入组织管理页面
- 预期：成功进入组织管理页面，左侧组织结构树存在一级组织

#### 步骤3：选择一级组织并进入组织配额 tab
- 操作：在组织结构树中选择一级组织名称，点击"组织配额" tab
- 预期：组织配额 tab 页加载完成无报错

#### 步骤4：过滤计算服务配额
- 操作：点击"计算"，过滤计算服务配额
- 预期：成功过滤出计算服务，页面存在：云服务器ECS、机密云服务器SECS、镜像服务IMS、裸金属BMS

#### 步骤5：分配计算配额
- 操作：依次修改各计算服务配额
  - 5.1 云服务器ECS：点击"修改配额"→修改 cpu总量(个)：1、内存总量(GiB)：1、系统盘总量(GiB)：1→点击确定
  - 5.2 机密云服务器SECS：点击"修改配额"→修改机密云服务器总量(个)：1→点击确定
  - 5.3 镜像服务IMS：点击"修改配额"→修改镜像总量(个)：1、镜像容量总量(GiB)：1→点击确定
  - 5.4 裸金属BMS：点击"修改配额"→修改软装版服务器总量(台)：1→点击确定
- 预期：
  - 5.1 绿色提示：更新根账号配额成功；云服务器ECS模块显示：cpu使用量(个):0/1，内存使用量(GiB):0/1，系统盘使用量(GiB):0/1
  - 5.2 绿色提示：更新根账号配额成功；机密云服务器SECS模块显示：机密云服务器使用量(个):0/1
  - 5.3 绿色提示：更新根账号配额成功；镜像服务IMS模块显示：镜像使用量(个):0/1，镜像容量使用量(GiB):0/1
  - 5.4 绿色提示：更新根账号配额成功；裸金属BMS模块显示：软装版服务器使用量(台):0/1
